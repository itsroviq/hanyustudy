# 汉语教程 Hanyu Jiaocheng

### Mandarin Mastery Academy

Hanyu Jiaocheng is an independent Mandarin learning application based on the Hanyu Jiaocheng learning pathway.

It covers levels 1A through 3B and provides an adaptive learning experience.

## ✨ Features

- Hanyu Jiaocheng 1A–3B
- Listening practice
- Speaking practice
- Reading practice
- Writing practice
- Grammar learning
- Adaptive Learning Intelligence
- Weakness analysis
- Recommended practice
- Volume examinations
- Learning progress visualization

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the main HTML file in a modern browser.
3. Select a learning volume and begin studying.

## 🛠️ Technology

- HTML5
- CSS3
- JavaScript
